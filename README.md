# CML Lab

Static web application featuring 11 CML Lab Python programs with one-click copying and mobile-first responsive design.

## Features

- Exactly 11 experiment topics displayed in clean, accessible boxes.
- Full Python code rendered with preformatted blocks preserving syntax, indentation, and structure.
- One-click Copy button with automatic clipboard fallback.
- Mobile-first, responsive, lightweight frontend built with React and Vite.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
